# Basic Website

This is a simple static website starter.

## Folder structure

```text
basic-website/
├── assets/
│   └── images/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
└── README.md
```

## Run

Open `index.html` in a browser, or serve the folder with a simple static server.
